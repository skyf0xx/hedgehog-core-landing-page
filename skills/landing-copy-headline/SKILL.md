# Landing Copy: Headline

The headline is the highest-leverage line on the page. Don't draft by
feel — generate from the patterns below and run the cold-read test on
every candidate.

This skill covers the headline only. The subhead beneath it is
`landing-copy-hero`'s job, run after this one locks.

## 1. Pull the material

Read, don't re-derive: the subject/audience/job statement, the adjective
pairs and their opposites, and the voice spec. Every candidate traces
back to one of these — a candidate that doesn't fails the check below.

## 2. Generate one candidate per pattern

- **Outcome.** State what the reader gets. "Build software that holds
  together."
- **Transformation.** Current state → desired state. "Turn ideas into
  products people use."
- **Negative-outcome.** What stops happening, not what starts. "Stop
  losing state between sessions." Use when the pain point is sharper
  than the positive-framed promise.
- **Specificity.** Lead with a real number, name, or fact from the
  brief. "Ship in 3 days, not 3 sprints." Skip it if the material has
  no genuine figure — never invent or round one to fill the slot.

Each candidate must use a different pattern; multiple phrasings of one
idea aren't multiple candidates. Outcome and Transformation are always
in play; Negative-outcome and Specificity join only when they fit.

## 3. The cold-read test (run on every candidate)

Read only the headline, no subhead, as a first-time visitor would, and
check both:

- **Subject = the reader's outcome, not the mechanism.** The
  grammatical subject is what changes for the reader, not the product
  or feature that changes it.
- **Legible with zero prior context.** Every term lands without the
  reader having already inferred a frame, tension, or stance the line
  itself never states.

- "One signature. Three uses." **fails** — subject is the signature,
  not the outcome.
- "Your website isn't a brochure. It's a decision engine." **fails** —
  requires accepting "brochure" as the wrong frame before it lands.
- "Your agent's work outlives the session that made it." **passes** —
  outcome-subject, legible cold.

Rewrite or cut anything that fails before Step 4 — no pattern is exempt
from the test.

## 4. Apply the writing standard

- **No inflated words** — delve, landscape, robust, comprehensive,
  leverage, seamless, cutting-edge, elevate, unlock, empower, streamline,
  game-changer, harness, revolutionize.
- **No "It's not X — it's Y."**
- **No em dashes.** Comma, period, or restructure.
- **Concrete over abstract.** A claim like "significant improvement"
  ships only with the number, name, or comparison that makes it
  checkable. No source, no claim in that form.

## 5. Select and present

Present every candidate that survived Steps 3 and 4, labeled by
pattern — never fewer than 2. This is a hard stop — wait for an
explicit pick (the rest stand as backups) or a redirect. Every section
after this is checked against whichever headline locks here.

## Self-test

- Every candidate is a distinct pattern — never two phrasings of the
  same one.
- Every candidate traces to a named adjective or the subject statement —
  a line that could run unchanged on a competitor's page gets rewritten
  here, not left for the traceability check downstream.
- Every candidate passed the cold-read test individually, not waved
  through because the set "feels balanced."

## Constraints

- Never present fewer than 2 distinct-pattern candidates.
- Never invent or round a number to force a Specificity candidate.
- Never lock without the user's explicit pick — shown every candidate,
  labeled, no assumed choice.
- Never draft the subhead, section body, or CTA here.
